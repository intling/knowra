# Proposal

## Why

网申需要可分享的演示入口，让面试官直接试用基于私有资料的带来源问答。共享演示账号需要服务端额度保护，避免换设备、重新登录或并发请求绕过限制。

## What Changes

- 创建普通成员演示账号，通过受保护 stdin 输入密码，可配置最近 60 分钟最多 3 次成功问答。
- 在检索与模型调用之前执行数据库持久化额度预留；失败、无资料与生成降级不扣额度，超限返回中文提示和 Retry-After。
- 登录页支持片段携带演示凭据，自动填表并清除片段，用户点击登录；不自动提交，不持久保存或记录凭据。
- 在既有公网域名部署用户体系与演示入口，替换本站临时 Basic 门禁，保留数据库、资料与模型配置。

## Capabilities

### New Capabilities

- `chat-quota`: 用户级滚动小时额度、原子并发预留、失败释放与 CLI 配置。
- `demo-login`: 演示凭据链接的表单填充、校验、地址清理及明确额度说明。

### Modified Capabilities

无。本变更依赖已完成的 `add-user-auth-rbac`，不修改检索、生成与来源内容契约。

## Impact

- 后端增加额度配置及使用事件表、Alembic 增量迁移、额度服务、search 准入依赖和 create-user 命令；无新模型依赖。
- POST /api/search 增加 429 `{code: chat_quota_exceeded, detail: 中文原因}` 与 Retry-After；原请求及成功响应保持兼容。
- 前端登录页新增演示链接处理；无密码常量、query 参数或本地存储凭据。
- 验收包含 RED/GREEN、真实 PostgreSQL 并发与迁移、浏览器预填登录、线上认证及备份恢复。迁移仅新增表，回退保留既有用户数据和迁移表；不复制任何旧用户私有资料到演示账号。
