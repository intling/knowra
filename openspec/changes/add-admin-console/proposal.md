# 后台管理系统

## Why

现有用户管理仅支持列表、角色与启停，模型服务地址、密钥和模型名称只能由运维修改环境文件。管理员需要在统一后台维护账号生命周期和模型接入，让资料向量化、检索与带引用回答可以持续使用正确的服务配置。

## What Changes

- 提供 `/admin` 后台入口、用户管理与模型配置导航，保留 `/admin/users`，增加 `/admin/models`。
- 补齐管理员新增用户、重置他人密码、软删除用户；复用既有角色变更、禁用/启用、分页、会话撤销与最后一位管理员保护。
- 支持聊天、Embedding、重排、查询改写四类模型配置的新增、编辑、删除、启停与默认配置切换；首版接入现有 OpenAI 兼容协议及现有重排协议。
- 模型配置持久化，API Key 加密保存、永不回显；未设置后台默认配置时沿用环境配置。保存后下一次请求使用新配置，在途请求使用已有快照。
- 新增 `models:manage` 权限，仅管理员持有；管理员权限不扩展任何用户私有资料的可见范围。
- 限制不兼容的 Embedding 模型切换，避免既有向量索引与查询向量混用。

## Capabilities

### New Capabilities

- `admin-console`：后台入口、导航、表单状态、权限反馈与确认交互。
- `admin-user-lifecycle`：在已实现的认证及 RBAC 基础上补齐管理员建号、重置密码和软删除。
- `model-configuration`：多用途模型配置持久化、密钥保护、默认配置及运行时解析。

### Modified Capabilities

无。本变更基于已完成但未归档的 `add-user-auth-rbac` 与 `add-demo-access` 工作区，不重写其工件；新的管理能力通过上述增量规范定义。

## Impact

- 前端：扩展现有用户页和账户菜单，增加后台布局、模型配置页与统一 client API 封装；沿用项目视觉令牌，支持 320px 移动端。
- 后端：扩展 `/api/admin/users`，新增 `/api/admin/models`；增加配置服务与运行时配置依赖，接入搜索、自动向量化及重新向量化路径。
- 数据库：增加 `model_profiles` 与 `model_bindings` 表、四种用途绑定种子记录和 Alembic 迁移；既有用户和资料不迁移、不物理删除。
- 配置及依赖：新增环境变量 `MODEL_CONFIG_ENCRYPTION_KEY` 与 `cryptography` 依赖，用 Fernet 保存模型密钥；现有模型环境变量继续作为回退配置。
- 验收：真实 Cookie API 测试覆盖权限、用户生命周期、秘密不回显、配置切换与向量兼容性；前端覆盖新增/改密/删除/配置操作、失败提示及路由；完成 lint、测试、构建、PostgreSQL 迁移与浏览器验证。
- 回滚：清空后台用途绑定即可恢复环境配置；回退版本前执行新增迁移的 downgrade，仅移除模型配置表，不改变用户、凭据、会话及私有资料。加密主密钥必须独立备份，缺失时写入与解密均应明确失败。
- 范围：本期不引入自定义角色、权限点编辑器、组织租户、账单、资料代管、模型评测或自动重建向量索引，也不提供任意协议适配与模型连通性探测。
