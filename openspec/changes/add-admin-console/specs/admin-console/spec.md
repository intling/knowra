## Purpose

为管理员提供统一的后台导航与操作界面，在既有登录和权限边界内维护用户及模型服务，明确表达加载、成功、失败和确认状态，使管理工作可以通过键盘、读屏和移动端完成。

## ADDED Requirements

### Requirement: 后台入口与导航
前端 SHALL 提供 `/admin` 后台入口并导航到 `/admin/users`，后台包含用户管理、模型配置和返回知识库入口，模型配置地址为 `/admin/models`。

#### Scenario: 管理员进入后台
- **WHEN** 管理员打开账户菜单并选择后台管理
- **THEN** 系统 MUST 显示后台导航并可在用户管理和模型配置之间切换
- **AND** 原有 `/admin/users` 书签 MUST 继续可用

#### Scenario: 访客与普通用户
- **WHEN** 访客访问任意后台地址
- **THEN** 系统 MUST 跳转登录并保留安全站内返回地址
- **WHEN** 成员或只读用户访问后台页面
- **THEN** 页面 MUST 显示权限不足且 MUST NOT 请求管理员数据

### Requirement: 用户生命周期操作界面
用户管理页 SHALL 支持新增账号、重置密码和软删除，并保留分页、角色变更、禁用与启用功能。

#### Scenario: 新增账号
- **WHEN** 管理员填写邮箱、名称、初始密码、确认密码、角色并提交
- **THEN** 页面 MUST 校验必填项、密码策略和两次密码一致性
- **AND** 成功后 MUST 更新用户列表并清空密码，失败时 MUST 显示具体原因且不关闭表单

#### Scenario: 重置密码
- **WHEN** 管理员为他人填写新密码和确认密码并确认重置
- **THEN** 页面 MUST 调用重置接口并说明目标用户需要重新登录
- **AND** 当前账号的重置入口 MUST 引导至账户设置

#### Scenario: 删除账号
- **WHEN** 管理员选择删除其他账号
- **THEN** 页面 MUST 先展示目标邮箱、立即失效说明及保留历史资料说明
- **AND** 取消 MUST NOT 调用删除接口，成功后 MUST 更新总数和分页
- **AND** 删除当前页最后一项后 MUST 回到有效页码

### Requirement: 模型配置操作界面
模型配置页 SHALL 按用途展示配置名称、地址、模型标识、启用和默认状态，并提供创建、编辑、启停、设为默认、恢复环境配置和删除。

#### Scenario: 新增与编辑配置
- **WHEN** 管理员编辑模型服务信息
- **THEN** 表单 MUST 展示用途、配置名称、API 地址、模型标识、密码类型的 API Key 和超时
- **AND** Embedding MUST 展示受限维度，重排 MUST 展示现有协议选择
- **AND** 编辑时密钥框 MUST 留空并说明留空保留原密钥，界面 MUST NOT 用遮罩文本冒充真实密钥提交

#### Scenario: 生效与恢复
- **WHEN** 管理员确认设为默认或恢复环境配置
- **THEN** 界面 MUST 更新该用途的默认状态并说明下一次请求生效
- **AND** 向量不兼容或默认配置删除被拒绝时 MUST 保留原状态并显示后端具体原因

### Requirement: 状态反馈与可访问性
后台 SHALL 延续已有视觉令牌和确认组件，适应 320px 宽屏，所有控件具有标签并支持键盘操作。

#### Scenario: 请求进行中或失败
- **WHEN** 列表或表单请求正在执行
- **THEN** 页面 MUST 显示进行中状态并阻止重复提交
- **WHEN** 请求失败或列表为空
- **THEN** 页面 MUST 展示可读失败原因或空状态，保留恢复操作入口

#### Scenario: 秘密与焦点管理
- **WHEN** 密码或密钥表单关闭或提交成功
- **THEN** 页面 MUST 清除秘密输入，MUST NOT 写入日志、URL 或浏览器持久存储
- **AND** 模态层 MUST 循环 Tab、支持 Esc 关闭顶层并归还触发控件焦点
