# 流式问答与生成反馈

## 背景

模型适配器已使用供应商 SSE，但服务端会收集整段正文后返回 JSON。用户在较长回答生成期间只能看到占位提示，无法提前阅读。将真实正文增量传到主对话区，并提供安静、可访问的生成反馈。

## 范围

- `/api/search` 通过 `Accept: text/event-stream` 协商 SSE，保持原 JSON 请求和响应兼容。
- 串联模型增量、回答策略、长度续写、来源元信息、前端流解析与 Markdown 渲染。
- 提供真实阶段提示、生成光标、轻量渐入；尊重减少动态效果设置。
- 断流保留已生成正文与来源；关闭页面、身份切换或删除对话时取消连接并释放失败额度。
- 更新相关契约、README 和端侧工程约定，不增加依赖、数据库表、环境变量或新聊天入口。

## 验收

首个正文增量在模型结束前可见；连续增量准确拼接中文与 Markdown；正常结束显示最终来源和真实用量；中断保留正文并标为未完成；流期间不能重复发送同一对话；成功计额，失败、澄清、不完整及取消释放额度；旧 JSON 调用及历史记录兼容。

## 回滚

移除前端的流式协商即可继续使用同一路径的 JSON 接口。无数据迁移；已有本地记录继续可读。
