# 后台管理改版方案

## Why

现有后台已支持用户生命周期与四类模型配置，但仍由两个列表页组成。管理员难以判断“资料为什么不可检索、模型是否可用、账号是否超限、配置是谁改的”，排障需要转向数据库和服务器日志，影响私有资料接入到带引用回答的持续可用性。

## What Changes

- 将后台升级为独立管理工作区：侧栏导航、页头、筛选工具栏、表格、详情抽屉和统一反馈；`/admin` 改为进入运行总览，保留原用户和模型地址。
- 首期交付六个页面：运行总览、用户管理、模型服务、处理任务、操作审计、系统状态；具体页面结构、字段和低保真布局见 `design.md`。
- 用户管理增加服务端搜索和筛选、详情、最近 60 分钟问答额度查看与调整、撤销他人全部会话；复用已有账号创建、改密、软删除和管理员存续规则。
- 模型服务增加四用途生效配置概览、配置来源与版本、显式连通性测试；继续保护密钥和 Embedding 空间，不将保存等同于测试成功。
- 处理任务统一展示解析、分块和向量化的运行元数据、阶段状态与安全错误码；首期只读，不增加跨用户正文读取或代执行任务能力。
- 新增持久化操作审计，记录账号、额度、会话、模型变更和测试结果，按时间、操作者、动作、结果和 trace ID 检索。
- 系统状态展示数据库、pgvector、文档模型准备状态及诊断时间；未知或不可检查状态明确标记，页面刷新不自动调用付费模型。
- 后续候选包括用量与成本、基于自有测试集的检索评测、版本化 RAG 参数与告警；这些需独立变更定义，不属于本次实施任务。

## Capabilities

### New Capabilities

- `admin-workspace`：后台信息架构、运行总览、统一列表与详情交互、响应式及权限反馈。
- `admin-account-controls`：账号搜索、详情、滚动问答额度管理与会话撤销。
- `admin-model-diagnostics`：生效模型来源、版本、显式测试与结果失效规则。
- `admin-operational-monitoring`：内容隔离的任务监控和系统依赖诊断。
- `admin-audit-log`：持久化、字段白名单、事务一致的管理审计与查询。

### Modified Capabilities

无已发布主规范需要修改。本变更以上一个已完成但尚未归档的 `add-admin-console` 为基础；其“`/admin` 导航到 `/admin/users`”在本变更实施后由“导航到 `/admin/overview`”替代，其他用户生命周期、认证、密钥和向量一致性要求继续作为基线。归档或同步时须合并此后继规则，避免旧变更重新覆盖新入口；不改写前一变更的工作区工件。

## Impact

- 前端：重构 `AdminFrame`，保留现有用户与模型页面功能；新增四个页面及对应 API client，沿用 Vue、Tailwind、语义颜色令牌、本地字体和可访问性工具。
- 后端：扩展用户列表查询；新增管理员详情、额度和撤销会话接口，新增模型生效概览与测试、任务、总览、系统状态及审计接口。普通资料、检索、问答接口和引用结构不变。
- 数据：新增 `admin_audit_events`、`model_probe_results`，为模型配置增加 `revision`；复用用户、会话、限额和三类任务表，按查询计划补充索引；通过 Alembic 增量迁移。`chat_usage` 是会清理的额度预留数据，不能充当历史问答量或账单数据。
- 权限：新增 `operations:read`、`audit:read`，首期仅管理员拥有；额度和会话管理复用 `users:manage`，模型诊断复用 `models:manage`。新增管理员统计接口仅返回最小运行元数据，不修改既有按用户隔离的资料计数接口。
- 外部服务与配置：仅用户显式测试会访问已保存的模型配置，设总超时、无重试和服务端冷却；允许既有本机/私网模型部署，但阻止云元数据、链路本地地址和跨源重定向。新增配置仅控制测试超时、冷却和并发，不提供任意环境变量编辑器。
- 验收：六页可导航；搜索筛选作用于全量账号；额度调整与并发预留一致；成员和只读账号不能获取管理数据；管理员不能借任务或错误信息读取他人资料；模型测试不改默认；写操作与成功审计同事务；在 320px、768px、1440px 下验证完整工作流。
- 发布与回退：先部署增量表和向后兼容接口，再切换页面；保留原页面地址。回退前端后旧接口继续可用；回退代码时保留审计数据，不自动 downgrade 或删除历史记录。额度修改、账号禁用等业务操作不会随代码回退自动撤销。

本方案已获准进入实施，实际完成范围和验证结果以 `tasks.md` 与 `evidence/` 为准。
