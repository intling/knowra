1. 概述与目标

🎯 设计目标

将现有三页面（首页文件上传、对话验证、流程验证）重构为以对话为中心的两页面结构，新增侧边栏提供对话历史展示。

  • 对话与文件上传一体化（内嵌附件上传）
  • 新增左侧边栏：新建对话、历史对话
  • 流程验证保留独立页面，统一新视觉风格

📐 设计原则

专业克制的配色、清晰的层级、一致的间距
可靠操作有反馈、状态有提示、危险操作有确认
高效减少页面跳转、常用操作一键可达、批量处理

2. 信息架构与路由

路由结构

路由页面对应组件功能说明
/ 主页面 ChatLayout.vue 左右分栏布局。
左侧边栏：新建对话、历史对话列表。
右侧对话区：对话消息流 + 内嵌文件上传 + 对话召回验证（AnswerPanel / ResultsPanel / PromptPreview）。
/verify 流程验证页 VerificationView.vue 保留现有功能：选择已解析文档 → 执行全链路验证 → 展示解析/分块/向量化完整性检查结果。
统一新视觉风格（侧边栏替换为简化顶部导航）。
变更总结：删除 HomeView（功能合并入 ChatLayout），保留 VerificationView 并统一风格，新增 ChatLayout 作为主页面壳。

6. 主对话区详细设计

6.1 三态视图

🌅 空状态

触发：无活跃对话，未发送任何消息

  • 居中欢迎语："今天想了解什么？"
  • 副标题引导使用
  • 可选：显示 3-4 个推荐问题

💬 对话中

触发：已发送 ≥1 条消息

  • 消息流：用户问题气泡 + AI 回答卡片
  • AnswerPanel：Markdown 渲染，来源引用数统计
  • ResultsPanel：折叠式检索结果，按文档分组
  • PromptPreview：折叠式提示词预览

⏳ 加载中

触发：发送问题后等待响应

  • 用户消息立即可见
  • AI 回答区显示骨架屏动画
  • 发送按钮变为加载状态
  • 两阶段提示：搜索中 → 生成回答中

6.2 对话输入框（ChatInput 重构）

功能点现状重构后
文本输入✅ textarea，Enter 发送，Shift+Enter 换行保留
Top-K 调节✅ 滑块 1-50保留，移到输入框上方或折叠
文件上传入口单独的 📎 按钮 + 文件选择器 内嵌附件按钮 + 文件 chip 预览 + 上传状态指示
附件预览单个 chip + 删除按钮 支持多文件 chips，每文件独立删除
发送按钮✅ "发送" / "上传" 状态切换 保留，增加 loading spinner
快捷键Enter 发送，Shift+Enter 换行 保留，增加 Ctrl+Enter 换行
设计要点：对话区的文件上传是"轻量快捷上传"，适用于对话中临时引用资料。

7. 对话召回验证（主页面内嵌）

每次发送问题后，主对话区展示以下验证信息，均保留现有折叠面板交互：

面板组件位置默认状态
🤖 AI 回答 AnswerPanel.vue 用户问题下方 展开
📊 检索结果 ResultsPanel.vue AI 回答下方 折叠（用户手动展开）
💬 提示词预览 PromptPreview.vue 检索结果下方 折叠（用户手动展开）
验证流：输入问题 → Enter 发送 → "搜索中…" → "生成回答中…" → AI 回答展示 + 检索结果可展开查看 + 提示词可展开查看。所有状态切换在原对话区完成，不跳转页面。
